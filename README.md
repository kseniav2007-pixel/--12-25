# Эмулятор командной оболочки UNIX

## Описание проекта

Проект представляет собой учебный эмулятор командной оболочки UNIX-подобной операционной системы, разработанный на языке Python в рамках дисциплины «Конфигурационное управление».

Программа реализует интерактивный интерфейс командной строки (CLI), обработку пользовательских команд, настройку параметров запуска и автоматическое выполнение команд из стартового скрипта.

## Реализованная функциональность

### Этап 1. REPL и базовые команды

Реализован цикл REPL (Read–Eval–Print–Loop), обеспечивающий непрерывное взаимодействие с пользователем.

Поддерживаются следующие команды:

- `ls` — имитация просмотра содержимого каталога.
- `cd` — имитация перехода между каталогами.
- `exit` — завершение работы эмулятора.

Реализован парсер, разделяющий введённую строку на название команды и список аргументов.

На данном этапе команды `ls` и `cd` являются заглушками и выводят информацию о полученных аргументах.

### Этап 2. Конфигурация и стартовые скрипты

Добавлена обработка параметров командной строки с помощью библиотеки `argparse`.

Поддерживаются параметры:

- `--vfs` — путь к физическому расположению виртуальной файловой системы.
- `--script` — путь к файлу стартового скрипта.

Реализованы:

- Вывод параметров конфигурации при запуске.
- Построчное чтение стартового скрипта.
- Пропуск пустых строк и строк комментариев, начинающихся с `#`.
- Автоматическое выполнение команд.
- Имитация пользовательского ввода.
- Обработка неизвестных команд и ошибок чтения файлов.

## Структура проекта

- `main1.py` — основной файл эмулятора.
- `start.txt` — стартовый скрипт с последовательностью команд.
- `normal_test.bat` — проверка корректной работы программы.
- `error_test.bat` — проверка обработки ошибок.

## Запуск программы

Для запуска необходим установленный Python 3.

Запуск без дополнительных параметров:

`python main1.py`

Запуск с указанием пути к VFS:

`python main1.py --vfs ./vfs_data`

Запуск со стартовым скриптом:

`python main1.py --script start.txt`

Запуск с обоими параметрами:

`python main1.py --vfs ./vfs_data --script start.txt`

## Тестирование

Для проверки функциональности предусмотрены командные файлы Windows:

- `normal_test.bat` — проверка стандартных сценариев запуска.
- `error_test.bat` — проверка поведения программы при ошибках.

Тестовые файлы можно запускать через командную строку Windows или PowerShell.

## Ограничения

Проект находится на начальном этапе разработки.

Команды `ls` и `cd` пока не выполняют реальных операций с файловой системой. Параметр `--vfs` используется для передачи и отображения пути к виртуальной файловой системе.

Дальнейшие этапы предполагают расширение функциональности эмулятора.
